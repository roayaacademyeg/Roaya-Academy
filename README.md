# Roaya Academy — Website

**Roaya Academy** is an online coding and technology education academy for children and teenagers. Our goal is to make programming approachable, engaging, and practical, helping young learners build problem-solving skills, creativity, and confidence through hands-on projects.

**Tagline:** Inspiring Young Minds Through Code.


## About the Academy

Roaya Academy provides age-appropriate coding education for two main groups:

- **Kids (approximately 8–12 years):** A friendly introduction to computational thinking and programming fundamentals, including beginner-friendly tools and activities.
- **Teens (approximately 12–18 years):** A more structured pathway into programming, web development, and practical software projects.

Learning is project-oriented: students are encouraged to experiment, write code, debug problems, and apply what they learn. Course offerings and schedules may change; refer to the website or contact the academy for current availability.

## Learning Areas

Depending on the course and level, topics may include:

- **Scratch:** Visual programming and introductory logic.
- **Python:** Fundamentals, problem solving, functions, and object-oriented programming.
- **Web Development:** HTML, CSS, and JavaScript.
- **Databases and SQL:** Basic data concepts and querying.
- **Advanced Topics:** Selected introductions to data analysis, AI, or computer vision where appropriate for the student's level.

## Teaching Approach

- Age-appropriate explanations and progressive learning paths.
- Live instruction, practice, exercises, and project-based activities.
- A focus on understanding concepts rather than simply memorizing syntax.
- Encouragement of creativity, analytical thinking, and independent problem solving.

## STEM Instructor Credential

The website displays the supplied **STEM.org Certified Educational Instructor** badge. This badge refers to an **instructor credential**; it should **not** be interpreted as institutional accreditation or certification of Roaya Academy itself. The badge is presented as supplied, and its validity or current status has not been independently verified as part of this website update.

## About This Website

The Roaya Academy website introduces the academy, explains its learning paths and courses, and helps prospective students and parents explore the available programs and contact the team.

### Technology

- React 18 frontend (compiled production bundle)
- JavaScript and CSS
- Responsive layouts for desktop and mobile
- Arabic and English interface content
- Static hosting on Netlify

This deployment package contains **compiled assets**, not the original React source project. To make substantial changes to components or rebuild the application, use the original source repository if available.

### Deploy to Netlify

1. Extract the ZIP archive, if needed.
2. In Netlify, open the existing site and go to **Deploys**.
3. Upload the deployment ZIP or drag the folder containing `index.html` into the deployment area.
4. Once published, verify that the homepage, navigation, language switching, course sections, images, and contact links work on desktop and mobile.

**Important:** `index.html` and the `assets` folder must remain at the deployment root. The site uses absolute `/assets/...` paths.

# عن أكاديمية رؤيا

**أكاديمية رؤيا (Roaya Academy)** أكاديمية لتعليم البرمجة والتكنولوجيا للأطفال والمراهقين، وتهدف إلى تبسيط المفاهيم التقنية وتنمية مهارات التفكير المنطقي وحل المشكلات والإبداع من خلال التدريب العملي والمشروعات.

- **الأطفال (تقريبًا من 8 إلى 12 سنة):** مقدمة مناسبة للعمر في التفكير البرمجي وأساسيات البرمجة.
- **المراهقون (تقريبًا من 12 إلى 18 سنة):** مسارات أكثر تقدمًا في Python وتطوير الويب والمشروعات العملية.

تشمل مجالات التعلم، وفقًا للمستوى والبرنامج، Scratch وPython وHTML وCSS وJavaScript وقواعد البيانات وSQL، بالإضافة إلى موضوعات تقنية متقدمة مناسبة للمستوى.

**أسلوب التعلم:** شرح تدريجي، وتطبيقات عملية، وتمارين، ومشروعات تساعد الطالب على الفهم والتجربة وبناء الثقة.

**توضيح بخصوص STEM:** الشعار الموجود بالموقع يخص شهادة **STEM.org Certified Educational Instructor** للمدرّس، ولا يعني بالضرورة أن الأكاديمية نفسها معتمدة كمؤسسة من STEM.org. لم يتم التحقق المستقل من حالة الشهادة ضمن هذا التحديث.


يمكن معرفة تفاصيل البرامج والتسجيل والتواصل من خلال الموقع الإلكتروني.
